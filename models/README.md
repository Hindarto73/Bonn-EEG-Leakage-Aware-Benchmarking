# Machine Learning Models

This folder contains machine learning model implementations evaluated in the Bonn EEG multiclass classification framework.

The evaluated models include:

- Random Forest
- XGBoost
- LightGBM
- Support Vector Machine with RBF kernel (SVM-RBF)
- Multilayer Perceptron (MLP)

Additional experimental configurations:

- XGBoost with feature selection
- XGBoost with SMOTE augmentation
- XGBoost with feature selection and SMOTE augmentation

All models are evaluated using the same leakage-controlled validation framework.
